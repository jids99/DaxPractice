DAX Practice

Jargon in plain English
  • Measure: a formula that gives one number, like total sales.
  • Filter context: whatever slicers, rows and columns are narrowing the data right now.
  • Table vs value: a table is a list (e.g. of dates); a value is one number you can show on a card.
  • Iterate (the X functions): go row by row, calculate, then combine.
  • Blank vs zero: blank means no data; zero is a real number. Averages skip blanks.
  • Rolling window: the last N days, sliding forward one day at a time.
  • YTD / QTD / MTD: year, quarter, month to date.
  • Date table: one row per day with no gaps, marked as the date table.
